# 游戏机制侦察员

- itch.io New & Popular

## 每个候选提取
- 3–10 秒 Hook
- 最小操作
- 单局时长
- Fail/Retry 或 Grow/Upgrade Loop
- Replayability
- Social / leaderboard potential
- IAA / IAP / Hybrid
- 2D / 3D、素材、后台和 LiveOps 负担
- 热度 Proxy 与新鲜度
- IP/克隆风险

搜索量不是小游戏首要信号。
